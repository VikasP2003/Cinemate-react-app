# 🎬 Cinemate Plus

Cinemate Plus is a modern movie browsing web application built using React and Vite.  
It allows users to explore trending, upcoming, popular, and top-rated movies with a clean and responsive UI.

🌐 Live Demo: https://cinemateplus.netlify.app/

---

## 🚀 Features

- 🔥 Browse Popular Movies
- 🎥 View Upcoming Movies
- ⭐ Explore Top Rated Movies
- 🌙 Dark Theme Support
- 📱 Fully Responsive UI
- 📝 Movie Details & Reviews
- 🔍 Search Movies
- ⚡ Fast Performance with Vite
- 🎨 Modern UI using Tailwind CSS
- 📡 Real-time Movie Data from TMDB API

---

## 🛠️ Tech Stack

### Frontend
- React

- React Router DOM

### Backend / API

## ⚙️ Setup & Installation

### Prerequisites

Make sure you have installed:

- Node.js (v18+)
- npm

---

### Clone Repository

```bash
git clone https://github.com/VikasP2003/Cinemate-react-app.git
```

---

### Install Dependencies

```bash
npm install
```

---

### Run Development Server

```bash
npm run dev
```

---

### Build for Production

```bash
npm run build
```
